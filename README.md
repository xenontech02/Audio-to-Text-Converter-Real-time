# Audio-to-Text-Converter-Real-time

This project is an Audio to Text Converter that captures audio from the microphone, converts it to text using Google Speech Recognition, and visualizes the audio signal and its frequency spectrum in real-time.

## Features

- Capture audio from the microphone
- Convert captured audio to text using Google Speech Recognition
- Real-time visualization of the audio signal and its frequency spectrum
- Simple GUI using Tkinter

## Requirements

- Python 3.x
- PyAudio
- NumPy
- SpeechRecognition
- Tkinter
- Matplotlib

## Installation

1. Clone the repository:
    ```sh
    git clone https://github.com/xenontech02/Audio-to-Text-Converter-Real-time.git
    cd Audio-to-Text-Converter-Real-time
    ```

2. Install the required packages:
    ```sh
    pip install -r requirements.txt
    ```

## Usage

1. Run the [audio_to_text_converter.py](http://_vscodecontentref_/0) script:
    ```sh
    python audio_to_text_converter.py
    ```

2. Click the "Start Listening" button to start capturing audio.
3. Click the "Stop Listening" button to stop capturing audio.
4. The recognized text will be displayed in the text box.
5. The audio signal and its frequency spectrum will be visualized in a separate window.
